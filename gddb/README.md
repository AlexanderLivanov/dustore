# GDDB — личная база знаний

Не конспекты из интернета, а карта собственного понимания.
Цикл, под который сделан инструмент:

    прочитал → объяснил своими словами → нашёл дыру → исследовал → переписал

## Установка

1. Запусти в XAMPP **Apache** и **MySQL**.
2. phpMyAdmin → Import → `db/schema.sql`, затем `db/seed.sql`.
   Из консоли: `mysql -u root < db/schema.sql && mysql -u root < db/seed.sql`
3. Открой `http://localhost/gddb/`.

Если MySQL не под `root` без пароля — поправь `config.php`.

## Три оси, которые не смешиваются

| Ось | Таблица | Смысл | Сколько на заметку |
|---|---|---|---|
| Раздел | `sections` | где заметка живёт | одна |
| Теги | `tags` | по каким срезам всплывает | много |
| Связи | `article_links` | как знания зависят друг от друга | много, типизированные |

Типы связей: `prerequisite` (нужно знать заранее), `explains`, `used_by`, `related`.
Направление — `from → to`: «чтобы понять *from*, нужен *to*».

## Как работают `[[вики-ссылки]]`

Пишешь в тексте `[[Логические вентили]]`. При сохранении ссылки вытаскиваются
из текста и синхронизируются в `article_links` с `auto = 1`.

Если такой заметки ещё нет — она создаётся как **заготовка** (`status = stub`).
Список заготовок и есть бэклог обучения: он растёт сам из того, что ты не смог
объяснить, не упомянув.

Ручные связи (`auto = 0`), поставленные в панели, при пересборке не трогаются.

## Вопросы и уверенность

- **Вопросы** (`questions`) — дыры в понимании как отдельная сущность, а не абзац
  в конце текста. Все открытые видны на `questions.php` — это очередь на изучение.
- **Уверенность** 1–3: *пересказал* → *отвечу на вопросы* → *объясню с нуля*.
  Ставится честно и вручную. Это карта того, где тонко.

## Ревизии

История прошлых версий текста. Пишется не чаще раза в 10 минут при изменениях,
плюс вручную кнопкой «Версия». Смысл — через полгода сравнить, как ты объяснял
эту тему сегодня.

## Горячие клавиши в редакторе

| | |
|---|---|
| `⌘/Ctrl + S` | сохранить |
| `⌘/Ctrl + 1 / 2 / 3` | текст / пополам / превью |
| `⌘/Ctrl + \` | скрыть панель |
| `⌘/Ctrl + B` / `I` | **жирный** / *курсив* |
| `⌘/Ctrl + K` | обернуть в `[[ ]]` |

Автосохранение — через 1.5 с после того, как перестал печатать.

## Файлы

    config.php        подключение к БД
    lib/core.php      PDO, слаги, Markdown, синхронизация графа
    api.php           единственный JSON-эндпоинт (?action=...)
    index.php         каталог: разделы, теги, статусы, поиск
    note.php          просмотр заметки
    editor.php        фулскрин-редактор с правой панелью
    questions.php     все открытые вопросы
    db/schema.sql     схема
    db/seed.sql       первые 10 тем + связи между ними

## Markdown

Поддерживается намеренно немного: `##`–`####`, списки, `>` цитаты,
` ``` ` блоки кода, `---`, `**жирный**`, `*курсив*`, `` `код` ``,
`[ссылки](url)` и `[[вики-ссылки]]`. Один рендерер на просмотр и на превью.

## Как писать заметку

Не как учебник. Как объяснение человеку, который не знает ничего.
Первая версия будет неточной — это нормально, для этого есть ревизии.
Когда натыкаешься на «а почему вообще…» — не додумывай, а заводи вопрос.
